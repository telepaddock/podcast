Política de Privacidade

Última atualização: 22 de novembro de 2026.

Esta política descreve como o Tele Paddock (o podcast e videocast em telepaddock.github.io/podcast, e o aplicativo de publicação "Tele Paddock" usado pela própria equipe) trata dados pessoais.

1. Quem usa o aplicativo

O aplicativo "Tele Paddock" que solicita acesso a uma conta Google é uma ferramenta interna de publicação. Ele é usado apenas pela equipe do podcast, com a conta do próprio canal. Ele não é oferecido ao público e não pede acesso à conta de ouvintes ou espectadores.

2. Dados do Google acessados e para quê

  • Envio de vídeos (YouTube Data API, permissão youtube.upload): publicar no canal Tele Paddock os episódios aprovados pela equipe, com título, descrição e miniatura.
  • Leitura de comentários (permissão youtube.force-ssl): ler os comentários públicos dos vídeos do próprio canal para contar os votos das enquetes ("vote 1 ou 2"). Cada canal de autor conta como um voto. O texto dos comentários é usado apenas para essa contagem e não é guardado; o resultado guardado é só o total de votos de cada opção.

O token de autorização fica guardado apenas no computador da equipe que faz a publicação e nunca é compartilhado.

3. O que não fazemos

  • Não vendemos, alugamos nem compartilhamos dados pessoais com terceiros.
  • Não usamos dados do YouTube ou do Google para publicidade, perfilamento ou para treinar modelos de inteligência artificial.
  • Não pedimos acesso a contas de ouvintes ou espectadores.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

O Tele Paddock usa os Serviços de API do YouTube. Ao assistir ou interagir com o conteúdo do programa no YouTube, você concorda com os Termos de Serviço do YouTube, e os dados tratados pelo Google seguem a Política de Privacidade do Google. Os dados obtidos pela API (estatísticas e comentários públicos dos vídeos do próprio canal) são guardados por no máximo 30 dias e apagados quando o acesso é revogado.

4. Ouvintes e espectadores

Este site não usa cookies nem rastreadores. Ao assistir no YouTube ou ouvir em aplicativos de podcast (Spotify, Apple Podcasts e outros), valem as políticas de privacidade dessas plataformas. Comentários publicados no YouTube são públicos por natureza.

5. Seus direitos e como revogar o acesso

A conta dona do canal pode revogar o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions. Para dúvidas, correções ou pedidos sobre dados pessoais, inclusive os previstos na Lei Geral de Proteção de Dados (LGPD), escreva para telepaddock@gmail.com.

6. Alterações

Mudanças nesta política serão publicadas nesta página, com a data de atualização.
